# Qime

Qime is a platform that helps brands monitor, measure, and improve their visibility in the responses and answers of AI-powered search engines and chatbots like ChatGPT, Perplexity, Gemini, and Google's AI Overviews (SGE).

## Overview

- Next.js 16 web application (React 19, TypeScript, Tailwind CSS v4)
- Documentation under `docs/`
- Database migrations under `migrations/`
